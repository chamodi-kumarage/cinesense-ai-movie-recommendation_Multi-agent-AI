# Step 11 — Similar Movies UI Simplification

The Similar Movies window has been simplified at the user's request.

Removed from the user interface:
- `2 · Ready-made mode`
- `3 · Optional filters`

The window now focuses only on selecting one or more similarity types and viewing explainable ranked results.

Backend similarity capabilities remain intact for compatibility. The simplified frontend submits the selected similarity factors using the standard overall weighting profile and no optional filters.
